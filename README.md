# YumiCare (Credibility & AI Backend)

The core backend and AI infrastructure for YumiCare. A TypeScript monorepo featuring a Postgres/Express API and custom YOLOv8 models for automated fetal ultrasound biometry and clinical analysis.

## Features
- **AI-Powered Diagnostics:** YOLOv8 integration for automated fetal measurement.
- **Robust Backend:** TypeScript, Express 5, and Drizzle ORM.
- **Clinical Management:** Secure patient, doctor, and appointment workflows.
- **Scalable Architecture:** pnpm monorepo structure ready for Supabase expansion.
